ЕЖЕДНЕВНИК — офлайн-сборка (статический сайт, WASM/Pyodide)
=============================================================

Что это
-------
Полностью автономная версия «Ежедневника»: Python-код исполняется прямо
в браузере (WebAssembly/Pyodide), сервер не нужен. После первого открытия
приложение работает без интернета: открывается офлайн, входит в аккаунт
по сохранённой сессии, показывает интерфейс. Синхронизация задач с Firebase
происходит при наличии сети.

Как разместить (GitHub Pages, бесплатно)
----------------------------------------
Важно: GitHub загружает через сайт файлы НЕ БОЛЬШЕ 25 МБ каждый.
Наш zip весит ~26 МБ — сам архив не примется («Yowza, that's a big
file»). Это не страшно: Pages должен отдавать ФАЙЛЫ, а не архив.
Внутри сборки самый большой файл — 9,2 МБ, а всего файлов 97
(лимент веб-загрузки — 100 за одну партию), поэтому загружаем так:

1. Распакуйте архив на компьютере в папку.
2. Создайте ПУБЛИЧНЫЙ репозиторий: github.com/new → имя (например,
   ezhednevnik-offline) → Create repository.
3. На странице репозитория нажмите ссылку «uploading an existing file»,
   откройте распакованную папку, выделите всё (Ctrl+A) и перетащите
   содержимое в браузер: папки canvaskit/, pyodide/, assets/, icons/
   и файлы из корня. Дождитесь списка → Commit changes.
   (Если число файлов вырастет за 100 — грузьте двумя партиями.)
4. Settings → Pages → Build and deployment → Source: Deploy from a
   branch → Branch: main, / (root) → Save.
5. Через 1–2 минуты сайт будет по адресу
   https://<логин>.github.io/<имя-репозитория>/

Альтернатива (вообще без git): Netlify Drop (app.netlify.com/drop) —
перетащить распакованную папку, готово. Или Cloudflare Pages.

Как пользоваться на iPhone
--------------------------
1. Откройте адрес в Safari (ПЕРВЫЙ раз — при интернете: кэш собирается).
2. Поделиться → «На экран „Домой“» — иконка PWA.
3. Первый запуск грузится 20–60 c (распаковка Python-движка), повторные —
   быстрее; офлайн-запуск ~15–25 c.

Ограничения (честно)
--------------------
- Первый вход в аккаунт требует сети (Firebase). Дальше сессия хранится
  в localStorage и восстанавливается офлайн, пока токен свеж (1 час);
  по истечении потребуется сеть для обновления токена.
- Задачи СОХРАНЯЮТСЯ офлайн: после каждой правки локальная база
  автоматически копируется в хранилище браузера (localStorage, ключ
  db_snapshot_<uid>). Перезагрузка страницы, сворачивание PWA и
  офлайн-запуск показывают последние данные, в т.ч. сделанные без сети
  (при появлении сети они уедут в Firestore). Объём — до ~2,5 МБ JSON
  (тысячи текстовых задач); выход из аккаунта удаляет данные с устройства.
- Размер кэша ~40–70 МБ (зависит от браузера) — на iOS хватает квоты.
- При выходе новой версии: соберите заново (scripts/build_publish.sh),
  залейте поверх; SW обновит кэш у пользователей при первом онлайне.

Сборка проверена в десктопном Chromium: cold boot, reload, офлайн-reload,
вход в Firebase, экран задач, восстановление задач из офлайн-снапшота
(32 проверки db_persist + живой E2E). Скрипты сборки — в репозитории
проекта (scripts/build_publish.sh, scripts/make_wasm_sw.py).
