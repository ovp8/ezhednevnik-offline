ЕЖЕДНЕВНИК — ПАТЧ PUSH-СЕРВЕРА (для GitHub Pages)
====================================================

В архиве 3 файла. Каждый кладётся В КОРЕНЬ репозитория ezhednevnik-offline
(там же, где лежат index.html, app.tar.gz и другие файлы приложения):

  push-bridge.js   — ЗАМЕНИТЬ существующий. Мост: звук, подписка push,
                     загрузка расписания на сервер, баннер «Включить
                     напоминания».
  push-setup.html  — ЗАМЕНИТЬ существующий. Страница включения/проверки
                     уведомлений (тестовый push теперь идёт через сервер).
  sw.js            — ЗАМЕНИТЬ существующий (если есть). Service worker
                     push-событий.

ПОРЯДОК ДЕЙСТВИЙ:
  1. Сначала задеплойте push-сервер на Render (см. README набора
     «Ежедневник_push_server») и получите адрес вида
     https://<имя>.onrender.com
  2. Если имя сервиса НЕ ezhednevnik-push — откройте push-bridge.js,
     в начале файла в строке PUSH_SERVER впишите ваш адрес, сохраните.
  3. Загрузите все 3 файла в репозиторий GitHub Pages (Add file →
     Upload files → Commit).
  4. Через минуту откройте приложение на iPhone: вверху появится баннер
     «Включить напоминания» → нажмите → «Разрешить».

ПРОВЕРКА:
  Откройте https://ovp8.github.io/ezhednevnik-offline/push-setup.html
  → статус «Уведомления включены ✓» → «Проверить уведомление» —
  должно прийти тестовое уведомление.
